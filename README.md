# Travel Website Template

## Overview
This project is a responsive travel website template designed for showcasing travel destinations, tourism services, and trip planning interfaces.

The project focuses on frontend web development using HTML and CSS to create a modern, visually appealing, and user-friendly travel platform interface.

This website template can be adapted for:
- Travel agencies
- Tourism platforms
- Vacation booking services
- Personal travel blogs
- Destination showcase websites

---

# Project Objectives

The main objectives of this project are:

- Design a modern travel website interface
- Practice responsive frontend development
- Create reusable website templates
- Improve UI/UX design skills
- Develop structured and maintainable web layouts

# File Descriptions
1- `index.html`

Main homepage of the travel website.

Contains:

* Navigation bar
* Hero/banner section
* Travel destination presentation
* Main website structure

2- `register.html`

Registration page interface.

Provides:

* User registration form
* Input fields
* User interaction components

3- `register.css`

Stylesheet dedicated to the registration page.

Defines:

* Form layout
* Input styling
* Button styling
* Responsive behavior

4- `site_de_voyage.css`

Main stylesheet for the travel website.

Handles:

* Overall website design
* Layout structure
* Typography
* Colors and responsiveness
